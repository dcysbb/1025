# LBTEK EM-CS5-3

“位移台 → LBTEK EM-CS5-3”与原 PDXC3 面板独立。“硬件连接 → 设备连接”新增 LBTEK 卡片，支持真实 / 模拟模式、USB 设备选择、单次位移上限及三通道名称和单位。只有一个设备时可自动选择，多台设备必须指定官方 SDK 枚举的 USB 端口；此端口不是 COM 号，重新插拔后可刷新列表。原有现场配置不迁移、不覆盖。

三张 CH 卡片提供相对点动、按住连续移动、绝对定位、每轴 Home、停止、速度 / 加速度读写，以及原点、正负限位和开环坐标。每轴四个快捷位移可在展开区修改，独立位移量和快捷值保存在本机浏览器。SDK 数值沿用位移台单位，直线台为 mm、旋转台为 °；单位设置只修改显示标签，不换算设备数值。开环坐标来自控制器，不代表编码器实测位置。没有添加 Thorlabs 特有的 Optimize。

Home 调用厂家 `home`，不是将软件计数清零。通道未报告原点传感器时禁止 Home。回零行程由控制器决定，不受单次点动距离上限限制。按住移动使用厂家 `startDrive`，松开、取消、失焦、页面隐藏或退出面板时发送停止；服务端和原生 SDK 工作进程均检查一秒续期。通信失效时软件不能保证硬件已经停止，保持未确认状态并要求重新连接后停止恢复。

连接只枚举并打开 LBTEK 原生 USB、读取全部通道，不发送使能、参数写入、回零或移动。不会探测其他设备串口。摇杆状态显式显示；摇杆开启时阻止页面移动，可在空闲时切换控制权。单次点动固定一次 Jog，不使用设备中可能遗留的循环次数。速度和加速度提交后读回校验；轮询不覆盖正在编辑的草稿。参数不在重连时自动恢复。

## 官方运行库

来源为 [LBTEK 官方下载中心](https://www.lbtek.com/software) 的 EM-CSx-x SDK V1.0.1（2026-11-03），适用型号参考 [官方产品页](https://www.lbtek.com/product/520)。使用包内 Python SDK 的 Windows x64 DLL 与随附依赖；不执行厂家会自动运动的示例程序。

源码环境首次安装：

```powershell
backend\.venv\Scripts\python.exe -X utf8 scripts\install-lbtek-sdk.py
```

安装脚本校验整包 SHA256 `9a89d68ff049eb31637e079d244042911e7cafd0bffac1910ca97d874443563a`，仅提取五个运行文件到忽略入库的 `backend/vendor/lbtek`。也可通过 `LBTEK_SDK_DIR` 指定官方 x64 库目录。Windows 打包脚本安装并携带该目录，现场配置不进入安装包。模拟模式不加载 DLL；其他系统可开发和模拟，真实 USB 当前仅支持 Windows x64。

SDK 的原生调用在独立进程串行执行，超时终止失效会话，不重发运动指令。原包示例使用轴号 0–2，随包手册写 1–3；驱动在连接时用边界轴的状态和坐标查询确认编号，无法明确辨认时禁止运动。通道界面始终使用 CH1–CH3。

避免 SyncMotion 和自有控制台同时操作同一个 USB 设备。无法打开时错误直接提示断开 SyncMotion，并保留具体 SDK 返回值。正式控制前先退出厂商软件的设备连接。当前 DLL 的坐标读取状态出参使用整数结果码（实机读到 0 表示成功、负数表示失败），驱动不按手册中的布尔描述把成功误判为失败。

## 服务接口

- `GET /api/lbtek-stage`：后台缓存状态、通道和最近 20 条本次运行的运动请求。
- `GET /api/lbtek-stage/devices`：只枚举官方 USB 设备端口。
- `POST /api/devices/lbtek/apply-connect`：按设备白名单合并配置，停止旧目标、断开、保存并连接；停止失败不换目标。
- `POST /api/devices/lbtek/cancel`、`disconnect`：取消后续连接或停止后断开。
- `POST /api/lbtek-stage/connect`、`action`、`parameters`、`stop`、`keepalive`、`rocker`：独立控制接口，沿用操作员与 Origin 校验。

所有运动记录写入现有事件日志，类型 `lbtek_move`，区分 submitted / rejected / unconfirmed。动作前原子保存恢复记录；进程中断、动作或停止结果未确认时保留锁定。连接不会清除锁定；全部停止并读取空闲后解除。停止请求撤销等待中的动作，未确认时不能更换目标。

验收使用驱动替身与独立模拟环境覆盖三通道映射、方向、范围、回零、并发拒绝、参数读回、续期、迟到响应和停止。正式设备只进行连接与只读状态检查，不能把模拟运动验收写成实机运动通过。
