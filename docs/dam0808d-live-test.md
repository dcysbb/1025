# DAM0808D 实机测试（2026-10-12）

USB 转 RS485：COM4，9600 8N1，设备地址 1。TPG366 保留 COM3，读取 CH4。

串口读取输入（02）和继电器状态（01）连续 20 次通过，八路输入和输出均为关闭，无状态变化。
用户授权测试未接负载的 OUT1：关闭 → 开启 1 秒 → 关闭。每次写入（05）回显及后续线圈状态读回通过，其余七路输出未改变，最终八路均关闭。

实机发现：接收期间动态修改 pyserial timeout 会调用 Windows 串口重配置，当前 USB 转换器因此丢失响应。驱动改为固定短读取超时，以整体截止时间约束分段读取；增加 USB UART 重配置和无响应超时回归测试。后端 50 项测试通过。
