# UI 设计风格与复用规范

本规范以当前真空联锁控制台为基线（2026-10-16，界面版本 `e04c4f5`），用于后续页面、组件和交互的持续扩展。设计定位是：**柔和玻璃质感的工业控制台**。整体克制、清晰、有层次；实时读数、设备状态和操作反馈优先于装饰。

尺寸记录的是当前默认基线，组件可根据用途调整。新增页面应遵守下述视觉语言和交互原则，不必复制旧页面中个别过小的辅助文字。

## 1. 整体视觉

- 深色默认采用蓝灰背景；浅色采用雾白与淡蓝灰。两套主题保持相同结构与信息层级。
- 页面背景使用低对比度的大面积渐变光晕；避免高饱和背景、大面积发光和强烈纹理。
- 面板采用半透明底色、细边框、柔和阴影与顶部内高光；通过明度和留白建立层次。
- 强调色是灰调蓝紫。绿色、琥珀色、红色承担明确的状态语义，不能随意当作装饰色替换。
- 图标统一使用 `lucide-react` 线性图标。普通图标约 14–18px，导航图标约 18px；图标、文字垂直对齐。

## 2. 主题与颜色

优先引用 `frontend/src/index.css` 中的语义变量，避免在业务组件中另建一套主题。

| 用途 / 变量 | 深色 | 浅色 |
| --- | --- | --- |
| 页面底色 `--bg` | `#0e131c` | `#edf1f6` |
| 面板 `--surface` | `rgba(25,33,46,.80)` | `rgba(255,255,255,.82)` |
| 实底浮层 `--surface-strong` | `rgba(29,39,54,.96)` | `rgba(255,255,255,.97)` |
| 主文字 `--text` | `#edf2fa` | `#25334b` |
| 次文字 `--muted` | `#a1afc3` | `#5c6b82` |
| 辅助文字 `--dim` | `#7f90a7` | `#6c7b91` |
| 强调色 `--accent` | `#a4b8ff` | `#5269b8` |
| 主按钮底色 `--accent-fill` | `#697fce` | `#5269b8` |
| 正常 / 就绪 `--green` | `#64dfbd` | `#138c70` |
| 提醒 / 模拟 / 待确认 `--amber` | `#ffc36a` | `#ad6b12` |
| 故障 / 危险 / 停止 `--red` | `#ff7b86` | `#c94050` |

边框使用 `--line` / `--line-strong`，输入底色使用 `--field-bg`，高光和阴影使用 `--highlight` / `--shadow`。通过主题变量调整颜色，保证浅色模式中的文字仍可读。

状态必须同时用文字表达。绿色只能表示对应状态成立，不能把“请求已下发”显示为“动作完成”。XYZ 轴和图表通道的颜色用于辨识对象，仍须配合轴名、通道名和独立状态标签。

## 3. 材质、圆角与间距

| 元素 | 当前默认基线 |
| --- | --- |
| 主面板 `.glass-panel` | 18px 圆角；半透明底色与弱渐变；1px 边框 |
| 背景滤镜 | `blur(20px) saturate(115%)` |
| 内层卡片 | 约 14–15px 圆角，使用更平实的输入底色或弱渐变 |
| 按钮 / 输入框 | 通常 10px 圆角；紧凑图表控件约 7px |
| 桌面内容面板内边距 | 22px |
| 手机内容面板内边距 | 16px |
| 页面区块间距 | 通常 18px；手机约 14px |
| 卡片间距 | 通常 14–16px；手机约 10px |

玻璃高光通过 `--glass-alpha` 调整，默认 `.072`；界面“玻璃强度”改变的是这一高光透明度，不应让主要文字随之变淡。浮层、表头和提示应使用足够实的底色，避免底层信息透过后影响阅读。

## 4. 布局与响应式

- 桌面采用“左侧导航 + 中部工作区 + 可收起的右侧事件栏”。顶部集中显示页面标题、主题、单位、运行模式和后台在线状态。
- 默认导航宽 248px，折叠后 76px；事件栏宽 304px。1500px 及以上分别为 260px / 330px。
- 1180px 及以下，事件栏改为浮层；展开导航宽 215px。760px 及以下采用顶部品牌栏、底部导航和单一内容流，事件栏在顶部下方浮出。
- 复杂工作区根据实际可用空间提前改列，例如 XYZ 轴卡在 900px 及以下改为单列。
- 内容容器使用 `min-width: 0` 与弹性网格。页面不产生横向滚动；宽表格可在自己的容器内横向滚动，不能挤压整页。
- 每张卡片围绕一个任务组织：标题与状态在上，参数或读数居中，操作和具体反馈在下。连接设置归“硬件连接”，运动操作归“位移台”。

## 5. 字体与信息层级

正文采用 `'DM Sans', 'Noto Sans SC', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif` 字体栈；数值、步数和坐标刻度优先使用 `'Cascadia Mono', Consolas, monospace`，并使用等宽数字 `tabular-nums`。

| 层级 | 当前常用字号 / 后续规则 |
| --- | --- |
| 页面标题 | 20–24px |
| 区块标题 | 15px 左右 |
| 普通控件与信息 | 当前多为 11–13px；新增关键正文、故障说明优先 12–14px |
| 辅助标签与说明 | 通常 10–11px；重要信息不能只靠小字表达 |
| 主要读数与轴标识 | 按重要性放大，轴字母约 30px；避免所有数字同样醒目 |

正文行高约 1.5，事件描述约 1.65。长故障信息允许换行并保留完整内容。不要通过缩小主要文字、裁切错误信息或降低对比度来塞入更多内容。

## 6. 控件、状态与反馈

- 主按钮使用强调色实底与轻微渐变；次按钮使用低对比底色和边框；危险操作采用红色文字、淡红底与明确动作名称。
- 普通按钮高度约 36px，输入框约 38px；位移方向按钮约 46px，全部停止约 42px。保留硬件控制入口足够的点击面积。
- 悬停和按下主要改变颜色、边框和阴影。控制按钮不因悬停或按下而位移、弹跳，尤其是停止与关闭入口。
- 键盘焦点使用 2px 强调色描边，并保留清晰的外偏移。图标按钮具备可读名称；折叠按钮具有 `aria-expanded` 和 `aria-controls`。
- 禁用操作时显示具体原因；请求中立即防止重复提交。停止入口具有独立请求状态，不受移动请求占用。
- 设备离线、状态过期、结果未确认应直接呈现；不能沿用旧数据假装在线或空闲。
- 保存区域独立显示“未保存”、成功反馈及具体错误。短暂消息可用 Toast，持续故障与禁用原因必须留在对应区域。
- 连接参数直接编辑，流程明确为“修改 → 保存 → 连接”。串口建议仅枚举系统设备，不限制手动输入；固定的驱动接口用说明文字展示，不伪装成只读输入框。后台状态读取失败时，已加载且有编辑权限的连接草稿仍可修改，保存与连接保持禁用，并说明原因。
- 错误提示说明操作对象、已知原因、当前影响和下一步。“Failed to fetch”属于页面与后台之间的请求失败，不能据此断言硬件离线；浏览器未提供具体原因时明确说明未知。轮询失败保留一条常驻提示并自动恢复，不反复弹 Toast；失败通知不能使用成功对勾。控制请求丢失响应时明确“结果未确认，勿重复提交”，不自动重发动作。
- 实机与模拟模式始终可辨认。页面进入、参数展示和动画本身不触发连接、输出使能、回零、移动或开阀。

## 7. 动效规范

动效用于解释布局和状态变化，采用短距离、轻量的淡入淡出与缓出。展开和收起必须成对设计。

| 场景 | 当前基线 |
| --- | --- |
| 悬停、焦点、边框与颜色 | `--motion-fast: 160ms` |
| 页面进入、折叠区高度 | `--motion-enter: 280ms` |
| 侧栏与主区布局变化 | `--motion-layout: 320ms` |
| 弹窗 / Toast 退出 | 200ms；退出占位最多保留约 220ms |
| 标签 / 事件栏透明度 | 约 180–220ms |
| 主要缓动 | `cubic-bezier(.22,1,.36,1)`，即 `--ease-out` |
| 进入 / 退出位移 | 通常 6–12px |

- 侧栏改变网格轨道宽度，主区同步伸缩；图标与切换按钮保留稳定锚点。不能仅给没有实际变化的 `width` 添加过渡。
- 折叠内容复用 `Disclosure` / `Reveal`，通过 `0fr ↔ 1fr` 实现自然高度变化；快速反向切换应从当前进度平滑返回，并保留已有输入。
- 弹窗与 Toast 复用 `Presence`，退出时保留短暂视觉内容，立即通过 `inert` / `aria-hidden` 禁止交互与辅助技术访问，随后清理节点。
- 硬件确认弹窗通过 Portal 放到页面顶层，避免玻璃滤镜建立的包含块裁切浮层；显式设置 `--pane-glass: var(--surface-strong)`，保证两套主题中的文字对比度，并约束键盘焦点与 Esc 取消。
- 动画不能延迟禁用、停止、权限撤销或错误显示。页面切换不能为了退出动画而让旧硬件控制页继续接受操作。
- 必须响应 `prefers-reduced-motion: reduce`：取消过渡和装饰动画，关闭流程直接完成；支持偏好在运行中变化。
- 避免 `transition: all`、过度弹簧和无意义的持续闪动。数据更新不应重复播放整页进入动画。

## 8. 曲线与表格

- 图表容器随宽度重新计算坐标；文字保持 CSS 像素大小，不能把整个 SVG 连同字号一起缩放。
- 常规曲线高约 340px，总览紧凑曲线约 230px。纵轴约 12px、时间约 11px、日期约 10px，使用稳定的等宽数字。
- 纵轴支持线性 / 对数及自动 / 手动范围。对数采用清楚的数量级刻度；线性采用易读间隔，必要时在标题统一标注科学计数倍率。
- 刻度数量受空间约束：当前对数总览最多约 5 个、完整图约 7 个；线性约 6 个。时间标签按显示跨度与宽度稀疏排列。
- 网格线保持轻、细，曲线颜色清晰而不过亮。CH1–CH6 固定使用紫、青绿、琥珀、蓝、粉红、黄绿顺序；浅色主题使用对应较深版本。
- 压力单位和北京时间明确显示；无效样本形成断点，不能用连线伪造有效读数。
- 表格以弱分隔线、对齐和适度留白区分行列；长原因允许换行。滚动表格的固定表头采用实底，防止内容透字。

## 9. 实现入口与验收

| 文件 | 职责 |
| --- | --- |
| `frontend/src/index.css` | 主题、颜色、字体与基础令牌 |
| `frontend/src/Appearance.css` | 共享玻璃材质、控件外观和基础进入动效 |
| `frontend/src/Motion.tsx` / `Motion.css` | 折叠、退出、侧栏和事件栏过渡 |
| `frontend/src/App.css` | 应用布局与基础组件样式 |
| `frontend/src/Chart.css` | 图表字号、工具栏、网格、图例与主题颜色 |
| `frontend/src/HardwarePanel.css` | 硬件连接、端子与阀门映射布局 |
| `frontend/src/TerminalWorkbench.tsx` | DAM 端子功能分配、输入反馈及输出控制；复用现有配置和控制接口 |
| `frontend/src/StagePanel.css` / `StageWorkbench.css` | 位移台工作区、方向操作和运动记录 |
| `frontend/src/StageAdvanced.tsx` / `StageAdvanced.css` | 输出、开环 Home/Zero、自动优化、驱动参数与连接诊断；操作确认与停止状态独立 |
| `frontend/src/StageToolHistory.tsx` / `stageProfiles.ts` | 控制器工具记录、驱动参数导入预览与导出；载入文件不触发硬件操作 |

位移台顶部提供功能直达导航。锚点定位预留固定控制栏的实际高度，不能让工具标题或错误被遮住。自动优化只展示实际阶段及等待时间；通信失效时改为“结果未确认”，不能继续显示进行中的进度，也不能用等待时间推算成功。

位移台只保留一个“精细控制”面板。X、Y、Z 每轴一张控制卡片，集中显示实际 CH 映射、型号、输出、开环命令计数与优化状态，并整合独立步长、点动、输出使能、Home / Zero 和 Optimize；不再另建一组控制器通道卡片重复显示状态。参数、连接诊断和工具记录收在同一面板下方。进入通道工具按钮区会立即撤销键盘点动。确认弹窗固定显示所点击的轴与通道，不能受参数通道下拉框影响；设备或映射变化时撤销确认。桌面并排、窄屏单列，全部停止仍是控制器级入口。

扩展时先复用共享类名、令牌与组件，再添加局部样式；局部覆盖应限定到相应业务容器，避免影响其他页面。主题和动效规则调整后同步更新本规范。

验收覆盖深浅主题、桌面和手机、长错误信息、加载 / 空数据 / 离线状态、键盘焦点、快速展开收起及减少动态效果。交互变更执行相关前端测试、构建和静态检查；实机环境只做读取与展示验收，硬件动作使用驱动替身或明确的模拟环境验证。

## 10. 可重复使用的调用提示词

> 请沿用本项目“柔和玻璃质感工业控制台”UI 风格，先阅读 `docs/ui-design.md`。使用蓝灰深色 / 雾白浅色双主题、灰调蓝紫强调色、半透明磨砂卡片、细边框、柔和阴影、统一线性图标和清晰的等宽数字。保持导航、卡片、表单和图表层级一致，为展开与收起补齐可逆过渡，并适配减少动态效果。所有硬件操作保持明确状态、禁用原因与稳定的停止入口；视觉修改不能触发设备动作。优先复用现有主题变量、共享组件和样式。
