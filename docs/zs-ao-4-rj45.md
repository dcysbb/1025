# ZS-AO-4-RJ45 压力电流输出

硬件连接 → 模拟量输出，独立保存 `analog-output.json`。四路 AO 可分别选择真空规 CH1–CH6、名称、4mA/20mA 对应压力（Pa）、线性/对数转换和压力失效/停止时电流。端点可反向设置，超范围限幅到 4–20mA；对数端点须大于零。

协议依据中盛科技《模拟量输出系列使用手册（RJ45版）》V2.0：[官网下载入口](https://www.zskjdg.com/fileResources)，模拟量输出分类中的原厂 PDF：

<https://zhongshengkeji.oss-cn-shenzhen.aliyuncs.com/产品资料/5模拟量输出系列/RJ45/模拟量输出系列使用手册(RJ45).pdf>

- 默认 TCP Server，IP 192.168.0.7、端口 8234、站号 1。驱动使用标准 Modbus TCP，不自动回退 RTU。
- 电流按 1µA/计数换算，12000 表示 12mA；06 功能码写单寄存器，校验回显。
- 手册第10–11页寄存器表给出 AO1–AO4 地址 0x000A–0x000D，第12页示例却从 0x0000 开始。控制台默认“待核对”，不通过试写判断地址。现场核对后选择实际起始地址。
- 连接只读站号（0x0032）和已选输出寄存器，不写电流或通信设置。寄存器设定值不能代替电流表测量。

2026-10-26 离线核查了手册链接的[厂家综合测试软件](https://zhongshengkeji.oss-cn-shenzhen.aliyuncs.com/常用软件/测试软件/中盛综合测试系统.zip)：`SystemLegend.table_CellButtonClicked` 将从零开始的行号传给 `WriteData(RowIndex, ReadSingleData)`，后者在 Modbus RTU/TCP 分支使用 `RowIndex + 10` 作为 06 功能码的寄存器地址。因此厂家软件与寄存器表一致，AO1–AO4 使用 `0x000A–0x000D`，示例中的 `0x0000` 不能作为该版本软件的依据。所核查 ZIP 的 SHA256 为 `BC4246A0E347FC7C1C338AF2830B3B65A703AC250639F0E43ED2A537EFCED04F`。该结论用于核对地址，不代表实测电流已验收；其他硬件或固件版本仍应核对。

后台使用已有有效压力样本，不额外占用真空规串口。线性转换为 `I=4+16×(P−P4)/(P20−P4)`；对数使用相应 `log10(P)` 比值。默认更新周期0.5秒，可设置0.2–10秒，实际周期还取决于网络应答耗时。

保存、连接和重启均不启用输出。需选定 AO 映射、填写量程、核对4–20mA型号及接线，再单独开始实时输出。真实模块拒绝使用模拟压力；运行中切到模拟压力会使用故障电流。

Debug → 四路模拟量手动调节支持独立设置 AO1–AO4 的 4–20mA 电流（0.001mA 精度），无需启用该通道的压力映射。数值、滑块及快捷值只修改待下发值；下发操作经 `POST /api/debug/analog-output`（`channel: 1..4`、`current_ma: 4..20`），沿用操作员权限与 Origin 校验。压力跟随运行时先通过“切换为手动调节”停止跟随并写故障电流，手动下发不会修改压力映射。手动输出期间禁止修改配置或启动压力跟随；停止会向实际手动操作过的通道写入对应故障电流。恢复记录包含手动通道，即使该通道未启用压力映射，异常重启后也不能绕过停止确认。手动值不作为启动时自动执行的配置。

每路 `offset_ma` 是手动校准的加法偏移，默认 0，范围 −16 至 +16mA，分辨率 0.001mA。下发值按整数微安计算 `clamp(目标电流 + 偏移, 4, 20)`，作用于压力跟随、Debug 手动调节和故障/停止电流，始终只加一次。状态中的 `target_ma` 为补偿前目标，`current_ma` 为实际下发的寄存器设定值，`calibration_limited` 表示补偿触及上下限，均不代表实测电流。端点处的误差可能因 4–20mA 限制无法完全补偿。

硬件连接可随映射一起保存偏移；Debug 提供每通道独立保存，调用 `PATCH /api/analog-output/calibration`，只提交 `channel` 与 `offset_ma`，不覆盖其他映射。保存前需停止输出，保存本身不写硬件，下次明确下发或启动压力跟随时生效。旧配置与旧恢复记录缺少偏移时按 0 迁移，恢复记录保留实际使用的校准参数。

压力过期、无效或真空规断联时使用故障电流。停止实时输出时同样写故障电流，“停止”不代表零电流。通信故障会锁定为“输出未确认”，停止自动发送；恢复通信后需先停止输出。`analog-output-recovery.json` 保存恢复记录，旧输出未确认时禁止替换映射或目标。

通信中断、进程崩溃或计算机断电后，软件不能保证模块改变最后电流。接收端需有独立断线/超时判断；手册未给出可核实的硬件通信超时失效输出设置，本轮不声称具备该保护。

模拟和驱动替身覆盖映射、故障电流、限幅、连接只读与恢复记录；接线、电流型号、起始地址和实际电流读数仍需现场验收。
