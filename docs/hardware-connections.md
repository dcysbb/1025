# 硬件连接

左侧“硬件连接”集中管理设备连接、DAM 端子和插板阀映射。“设置”保留运行模式、采样、保护阈值和访问设置；“位移台”保留运动与停止。

## 设备连接

- TPG366：USB 串口或 TCP，USB 使用配置的 COM 口和波特率，格式为 8N1。
- DAM0808D：USB 转 RS485 / Modbus RTU，使用独立串口、波特率及设备地址。
- ADAM6050：TCP / Modbus TCP；与 DAM 作为可选的 I/O 控制器型号，不能同时担任阀门 I/O。
- PDXC3：USB 或 TCP。USB 通过厂家 XA 仅按配置序列号匹配原生 USB transport，不探测 COM 口，不回退网口。TCP 保留明确 IPv4 或本机网段发现功能。

参数按设备分别保存，未保存时不能连接该设备。切换连接方式保留另一方式的参数。改变真空规或 I/O 连接配置后，本次服务运行等待该设备的显式连接操作；后台重启仍沿用原有启动行为。修改位移台连接、轴映射或步数上限前须断开位移台。

连接和查看配置不启用联锁、不启用位移台输出、不回零、不移动。真实设备仍须独立验收接线和阀门反馈。

## DAM 端子

物理端子定义按现有 DAM0808D 串口型厂家接口图展示：1–18 为电源、通信和输入端，19–38 为输出触点。IN1–IN8 对应机身 DI1–DI8、软件 DI0–DI7；OUT1–OUT8 对应 DO0–DO7。

OUT1–OUT4 各有 COM / NO / NC 三端，OUT5–OUT8 各为两端常开触点。固定电气定义只读。PB 端子仅保留厂家标识，软件不使用。通道名称最长 32 字，用途备注最长 160 字，各输入、输出保存 8 项。名称与备注不会改变继电器、保护状态或实际电气功能。

“DAM 端子”提供输出控制卡片和输入分配表。物理接线图收在“查看物理端子与接线图”中。

- OUT1–OUT8 可选择“普通继电器手动输出”或“插板阀电磁阀”。始终保留一个阀控输出；选择新的阀控通道时，原通道变为普通输出。
- IN1–IN8 可分配关闭到位、打开到位或仅监测输入，并指定反馈有效电平。关闭到位为必需项；先分配到其他输入，才能取消原输入的功能。输入是外部电平反馈，不能当作输出控制。
- 点击“保存功能分配”直接局部更新原有阀门映射，与“插板阀映射”页签共用同一份草稿和配置。更改选择不会立即操作继电器；未保存连接或映射时暂停吸合和开阀。名称、备注仍独立保存，不与功能分配混为一项。
- 普通输出的吸合 / 释放接入现有 `/api/debug/relays/{channel}`。吸合需要操作员权限、有效状态、联锁未启用及明确的现场手动控制确认。可以选择 1–60 秒后自动释放；未启用定时则保持，需手动释放。
- 当前已保存的阀控输出使用 `/api/valve/open` / `/api/valve/close`，保留正常开阀联锁。不会把阀控按钮转成绕过压力保护的原始继电器写入。正常关阀也会清除普通手动输出。
- 释放不受吸合请求占用；失去状态读取时保留释放尝试。响应丢失或结果不确定时禁止继续吸合，不自动重发，要求释放对应输出或关阀后核对反馈。

状态来自后台已有采样缓存。离线或数据过期显示未知；继电器状态读回仅表示线圈状态，不代表外接设备已完成动作，也不把吸合当作阀门已打开。物理设备动作仍以反馈和现场检查为准。

## 插板阀映射

当前支持单个插板阀、单路电磁阀控制：吸合请求开阀、释放请求关阀。可指定输出、关闭到位输入、可选打开到位输入和有效电平。打开与关闭输入不能重复。

连接或映射修改沿用撤销开阀许可、锁存保护流程，并清除受影响的现场验证确认。旧输出关闭无法确认时拒绝切换 I/O 或输出映射；切换同一 I/O 的阀控通道前，先撤销新通道输出。保存不会自动启用联锁或开阀。

## 接口兼容

- `GET /api/config` 与原 `PUT /api/config` 保留；新增 `PATCH /api/config`，请求体为 `{"config": {"字段": "值"}}`。后端在串行锁内合并当前配置、完整校验，禁止未知字段。新硬件页和设置页均使用局部保存，避免互相覆盖配置。
- `GET /api/hardware/ports`：只枚举系统串口信息，不打开端口。
- `GET /api/hardware/status`：读取设备状态及 I/O 缓存，不发起连接或输出指令。
- `POST /api/devices/connect-io`：只连接 I/O；真空规继续使用 `connect-gauge`，旧组合连接接口保留。
- `/api/stage/config` 新增 `connection: "usb" | "tcp"`，旧配置默认 TCP；位移台仍独立保存在 `stage.json`。

所有写接口沿用操作员权限和 Origin 校验。现有连接参数和映射不自动改写；新增端子文字默认留空。现场配置、数据库、日志和构建产物不入库。
